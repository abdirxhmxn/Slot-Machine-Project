# 🎰 Slot Machine
A fun and interactive slot machine game that simulates the classic casino experience in the browser.  
It was built to strengthen my front-end skills and showcase clean, organized game logic.


## How It's Made:

**Tech used:** HTML, CSS, JavaScript

The game is made up of three spinning reels that display randomized symbols each time the player clicks spin.  
JavaScript handles the logic for randomizing symbols, calculating wins or losses, and updating the player's credit balance.  
CSS brings it to life with animations, colors, and responsive layout, while HTML forms the basic structure of the game interface.

## Optimizations

I refactored the spin logic to be modular and reusable, making it easier to add more reels or symbols in the future.  
I also separated the UI updates from the core game logic to improve readability and maintainability.  

## Lessons Learned

This project helped me deepen my understanding of DOM manipulation and game loop logic.  
I also learned the importance of keeping UI logic and core logic separate, and how even simple animations can make an interface feel more polished and fun.
